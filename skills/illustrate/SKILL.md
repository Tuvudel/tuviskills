# Illustrate (router)

| Need | Open |
|---|---|
| Crafted isometric SVG figure explaining a system or idea (interactive or static) | anatomy |
| Data chart or dashboard: design or critique for integrity and data-ink | tufte-viz |
| Raster image prompts for product-research articles and reports | clean-product-research-illustrations |
| Ian-style Xiaohei character illustrations | ian-xiaohei-illustrations |
| Interactive HTML explorer with live preview | playground |
| Animated Codex pet or mascot | hatch-pet |
| Check text/background contrast inside a figure | apca-contrast |
| Screenshot the rendered figure to review it | playwright |

Optional, not installed: dedicated diagram skills (Mermaid, Excalidraw, D2, architecture diagrams). If one is installed later, add a row here. Until then, write Mermaid directly for simple flow and sequence diagrams and use anatomy for anything that needs craft.
