# QA Checklist

## Must Pass

- 16:9 horizontal image.
- Clean pure-white background.
- Xiaohei is present.
- Xiaohei performs the core action, not decoration.
- The composition does not copy old examples; it invents a metaphor for the current article.
- The image is strange, imaginative, and interesting.
- Clean and sparse; the subject does not exceed roughly 60% of the canvas.
- One image explains one core structure.
- English labels are sparse, short, and readable by default.
- Orange is used only for the main path or arrows.
- Red is used only for emphasis, problems, warnings, or results.
- Blue is used only for supporting notes, feedback, or system state.

## Failure Signals

Regenerate or locally edit if any of these appear:

- A top-left title such as "Common Traps", "Workflow", "System Architecture", or "Roadmap."
- Xiaohei looks like a mascot, meme, or cute cartoon.
- The image looks like PPT, courseware, or a formal flowchart.
- Too many elements, arrows, or nodes.
- Text becomes long explanation.
- Background has paper texture, shadows, gradients, beige, or noise.
- Real UI screenshot or techy interface.
- English labels are badly misspelled, garbled, too long, or unreadable.
- The image is stiff and lacks an absurd metaphor.
- The composition is too similar to `assets/examples/`.

## Iteration Methods

- Too ordinary: make Xiaohei the action subject and add one strange but fitting metaphor.
- Too complex: remove nodes; keep one action and 3-5 short labels.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too PPT-like: remove titles, formal frames, rigid grids, and excess arrows; turn it into a hand-drawn scene.
- Too similar to an old example: keep the core meaning, change the main object and Xiaohei's action.
- Bad text: prefer local editing; if text is very wrong, regenerate with fewer labels.

## Delivery Test

A high-quality image should make the reader first think "that's a little strange," then understand the structure within one second.

If the first impression is a tutorial slide instead of a strange sketch on white paper, it fails.
