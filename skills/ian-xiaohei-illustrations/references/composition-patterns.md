# Composition Patterns And Originality Rules

## Basic Structure Types

Choose one structure type. Do not mix too many.

### Workflow

Good for: input -> processing -> output, content production, AI workflows, automation chains.

Composition: input on the left, Xiaohei or a strange machine processing in the middle, output on the right. Use orange arrows for the main flow.

### System Close-Up

Good for: information sources, filters, databases, renderers, agent-system internals.

Composition: draw only 3-5 core modules. Xiaohei participates in one key action.

### Before-After Contrast

Good for: chaos/order, manual/automatic, scattered/collected, anxious/stable.

Composition: left side chaotic, right side stable, orange arrow in the middle. The character can be more exaggerated.

### Role State

Good for: user pain, creator state, too many tools, information anxiety, stuck-to-running transitions.

Composition: 2-4 small states, each with a short label.

### Conceptual Metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, automated report.

Composition: one large strange object or machine, a few inputs, one output. It should have a memorable hook.

### Layered Method

Good for: methodology frameworks, system layers, capability stacks, content-system layers.

Composition: loose stacked boxes, not a formal pyramid. Xiaohei builds, carries, or repairs the layers.

### Map Route

Good for: idea-to-launch, user path, content handoff, learning path.

Composition: one curving path with a few nodes. Xiaohei pulls a line or walks the route.

### Mini Comic Panels

Good for: failure-to-success, a real process, critique, before/after usage.

Composition: 2-4 tiny scenes. Each panel expresses one action only.

## Original Metaphor Method

Reinvent the metaphor from the current article every time. Do not copy old images.

### Three Steps

1. Turn the abstract concept into a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Turn the system structure into a low-tech object: broken machine, cardboard box, drawer, pipe, mailbox, strange dial, scale, well, ladder, odd workstation.
3. Let Xiaohei perform the action: stuck in the machine, pulling the wrong line, guarding a gate, carrying, repairing, weighing, holding a ladder, recording, stuffing something into a strange device.

### Object Pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of thread, gate, turntable, black box, hole punch, pasta roller, clothesline, strange workstation.
- Choose only 1-2. Do not crowd the image.

### Xiaohei Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, mark, recycle.
- The action must serve the core idea. Do not be strange just for strangeness.

## Anti-Copy Rule

Do not open or copy `assets/examples/` by default. Those images are only for occasional calibration of line density, whitespace, color restraint, and Xiaohei's tone.

Unless the user explicitly says "copy this composition" or "use this example," do not directly reuse these prior compositions:

- Conveyor belt with two breakpoints.
- Xiaohei pulling a judgment lever inside a content machine.
- Xiaohei as a funnel sorting traffic/trust/conversion.
- Xiaohei cutting a material fish.
- Xiaohei pulling a handoff path.
- Xiaohei pulling three layers of sources.
- Three Xiaohei figures holding a megaphone/building a bridge/opening a door.
- Xiaohei stamping a wording toolbox.
- Xiaohei holding a sign beside a common-traps path.

For similar themes, invent a new metaphor. A "handoff path" does not have to be a path; it might be Xiaohei attaching a content tail to a door handle. "One input, many outputs" does not need a fish; it might be Xiaohei pressing one paper ball into several shapes.
