## pstack by default

For any non-trivial engineering task (feature, bug fix, refactor, performance, review, CI, shipping, investigation), first read `{{POTETO_MODE}}` and follow it, including its playbooks and the skills it routes to. Open a routed skill by reading its `SKILL.md` in the folder next to poteto-mode (`../<name>/SKILL.md`); a slash command is not needed. Skip this for trivial questions, small talk, and one-line edits. User and project instructions win over pstack.

For non-code strategy or product decisions that can't be settled by prototyping or measurement, use the perspective-ensemble skill instead.

In Codex, also read `{{CODEX_ADAPTER}}` once per session and use it to map pstack's Cursor names (Task, subagent fields, model slugs, `.mdc` rules) to Codex.
