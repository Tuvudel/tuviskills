## Personal engineering workflow

For substantive code, architecture, debugging, review, or verification tasks, use the personal `engineering-companion` skill. At task start, after resume or compaction, and before entering a different Superpowers phase, read its routing instructions from the current skill catalog or `~/.agents/skills/engineering-companion/SKILL.md`. Load only the applicable supplement. Preserve the current approved stage and valid evidence; follow current plugin instructions and project rules. Include the companion path and applicable reference paths in delegated task briefs. Carry the current phase, approved-artifact pointers, and outstanding gates into handoffs. Skip this workflow for trivial edits and ordinary non-engineering conversation. The user can opt out for a task.
