## Findings

- 14 duplicate skill folders in Cursor match the Codex copies byte for byte.
- The `find-skills` junction in the original Codex folder is broken; no skill content was available to copy.
- `ui-ux-pro-max` has no YAML frontmatter. It is preserved as found; discovery can differ between agents.
- The local `skill-creator` and Superpowers skills overlap with bundled or plugin skills. Their existing contents are preserved.
- Skills can reference machine-specific paths or require MCP tools, packages, or browser access. Syncing files does not install those dependencies.
- System and plugin-managed skills remain managed by their applications and are not copied here.
